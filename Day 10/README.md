# What is Model Evaluation?

**Model Evaluation** is the process of measuring the performance of a machine learning model after it has been trained.

It compares the model's predicted values with the actual values to determine the model's accuracy and reliability.

---

# Why is Model Evaluation Important?

Model evaluation helps to:

* Measure the accuracy of predictions
* Identify model errors
* Compare different machine learning models
* Improve model performance
* Select the best model for real-world applications

---

# Evaluation Metrics Used

### Mean Absolute Error (MAE)

MAE measures the average absolute difference between the actual values and the predicted values.

* Lower MAE indicates better model performance.

---

### Mean Squared Error (MSE)

MSE measures the average of the squared differences between actual and predicted values.

* Lower MSE means fewer prediction errors.

---

### R² Score (Coefficient of Determination)

R² Score measures how well the model explains the variation in the data.

* **R² = 1** → Perfect prediction
* **R² = 0** → Model performs poorly

Higher R² values indicate better model performance.
