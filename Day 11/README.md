---

# What is a Prediction App?

A **Prediction App** is a program that accepts user input, processes it using a trained machine learning model, and provides a predicted output.

In this project, the application takes **study hours** as input and predicts the corresponding **student score** using a Linear Regression model.

---

# How Does the Prediction App Work?

The application follows these steps:

1. Load the student dataset.
2. Train a Linear Regression model.
3. Ask the user to enter study hours.
4. Use the trained model to predict the score.
5. Display the predicted score.
6. Allow the user to make another prediction.

---

# Features

- Loads the student dataset
- Trains a Linear Regression model
- Accepts study hours from the user
- Predicts the student's score
- Displays the prediction instantly
- Supports multiple predictions in one program execution
