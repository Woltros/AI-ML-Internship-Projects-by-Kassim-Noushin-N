# What is NumPy?

**NumPy (Numerical Python)** is an open-source Python library used for numerical and scientific computing. It provides a fast and efficient way to work with large collections of numerical data using **arrays**.

Unlike Python lists, NumPy arrays consume less memory and perform calculations much faster, making them ideal for data analysis and machine learning applications.

---

# Why NumPy?

NumPy is widely used because it:

- Provides fast and efficient array operations
- Simplifies mathematical calculations
- Supports multi-dimensional arrays
- Offers built-in mathematical functions
- Serves as the foundation for libraries like Pandas, Matplotlib, and Scikit-learn
