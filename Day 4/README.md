# What is Pandas?

**Pandas** is an open-source Python library designed for data manipulation and analysis. It provides easy-to-use data structures such as **Series** and **DataFrame**, making it simple to work with structured data.

Pandas allows users to load datasets, inspect data, clean missing values, filter records, perform statistical analysis, and prepare data for visualization and machine learning.

---

# Why Pandas?

Pandas is widely used because it:

- Simplifies working with structured datasets
- Provides fast and efficient data analysis tools
- Supports reading data from CSV, Excel, JSON, and databases
- Makes data cleaning and preprocessing easier
- Integrates well with NumPy, Matplotlib, and Scikit-learn
