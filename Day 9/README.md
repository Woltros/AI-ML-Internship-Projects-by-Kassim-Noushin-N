# What is Prediction in Machine Learning?

**Prediction** is the process of using a trained machine learning model to estimate the output for new, unseen input data.

Once a model has learned patterns from the training dataset, it can predict results for new values without needing the actual answers.

---

# Why is Prediction Important?

Prediction is one of the main goals of Machine Learning. It helps in making informed decisions based on historical data.

Some common applications include:

- Predicting student performance
- House price prediction
- Sales forecasting
- Weather prediction
- Stock market analysis
- Medical diagnosis

---

# What is Linear Regression?

**Linear Regression** is a supervised machine learning algorithm that predicts continuous numerical values by finding the best-fit linear relationship between input and output variables.

In this project, the model predicts a student's score based on the number of study hours.
